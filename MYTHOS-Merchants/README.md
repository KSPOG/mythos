# MYTHOS Merchants 0.1.0
Minecraft 1.21.1 / Forge 52.1.5 / Java 21. Standalone server mod with vanilla client trading screen.
16 templates: general, blacksmith, armorer, alchemist, food, farmer, materials, magic, fletcher, luxury, travelling, stable, pet, clan, dungeon, raid. The last five are empty placeholders for future integrations. Other templates have starter stock, prices are provisional. Travelling merchant is stationary and has no rotating stock yet.
Create at safe floor position: /merchant create blacksmith forge01 Emberfall Blacksmith
Right click to open standard villager trading UI. Native item-cost trades use emeralds by default; arbitrary registry items can be payment/result. Admin edits nearest managed NPC within 8 blocks; use /merchant info to verify identity first. IDs are labels unique only within nearby loaded search, entity UUID is authoritative.
Commands (operator level 2): /merchant types; /merchant create <type> <id> <name>; /merchant info; /merchant add <payment> <price> <item> <amount> <stock>; /merchant remove <1-based index>; /merchant restock; /merchant clear; /merchant rename <name>; /merchant delete.
Example: /merchant add emerald 5 iron_ingot 8 64. Use unqualified vanilla IDs or quote namespaced IDs.
NPCs, names, profession, tags, offer data and use counts persist in normal world entity NBT. No separate shop currency or database. NoAI, invulnerable persistent villagers. Native merchant transaction handling, one customer at a time; server tick closes sessions on range/dimension/disconnect or invalid entity. Admin editing closes current session. No custom menu protocol. Manual stock replenishment; no scheduled restock, remote shops, level/class gating, arbitrary RPG items, pet/mount collection unlocks or shared RPG gold yet. Native villager trade persistence, price behavior, interactions, range enforcement and restart must be tested live. Not claimed crash-atomic across player and chunk saves. Do not use as a production economy before integration and testing. CI pending.
