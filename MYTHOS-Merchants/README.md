# MYTHOS Merchants 0.2.0
Requires Economy 0.2.0, Forge 52.1.5 / Minecraft 1.21.1 / Java 21.
Right click a managed NPC for a vanilla-compatible chest shop. Left click buys one, right click sells one; shift-click trades ten. All quantities and prices are per individual item. Display stacks cannot be taken. Only plain vanilla item stacks with exactly default components are accepted for sales. No arbitrary custom item sales.
Create: /merchant create blacksmith forge01 Emberfall Blacksmith
Configure nearest merchant within 8 blocks: /merchant offer iron_ingot 100 50 128 256 false
Arguments: item, buy price, sell price, current stock, max stock, unlimited. Price 0 disables that direction. Unlimited ignores stock. Sell price cannot exceed enabled buy price. Namespaced IDs must be quoted. /merchant remove iron_ingot; /merchant info; /merchant restock (immediate); /merchant restock 3600 (interval seconds; 0 disables). Restocking lazily evaluated on access, refills maximum. All shops start empty intentionally; existing emerald offers are not imported. Native villager trades are disabled. Existing NPCs can be configured without respawn. No live JSON reload: stop server before editing mythos-shops.json. Up to 45 offers per NPC UUID. Admin edits nearest loaded NPC; verify /merchant info before changing.
Gold ledger has persistent idempotent merchant receipts. Shops save durable PREPARED/INVENTORY intents before/after inventory mutation, and stock changes at final commit. Unresolved trades block further trades for that shop and player. Owner permission 4: /merchant pending; /merchant resolve <transaction> <inventoryApplied>. Inspect actual inventory/player data and ledger first. true confirms inventory delivered/removed; false confirms it was not. Refunds are idempotent. Do not resolve blindly. PlayerList.saveAll is synchronous and Minecraft can internally swallow save errors; this is NOT crash-atomic across inventory, economy and shop files. Manual reconciliation is required after interruption. Do not deploy to production before testing. No automatic refund on uncertain inventory state. Do not edit pending transactions. Back up world files together. No NPC delete command in this release to preserve recovery records. Mount/pet unlocks, premium owner commands and RPG restrictions remain separate future work. No payment processing.

## 0.3.0
Stable and pet shops use registered creature providers and atomic economy purchases. /merchant mount add traveller gold 5000 10 false; /merchant pet add cat pet_token 250 5 false. Optional unlimited boolean, price/stock/remove/catalog subcommands. /merchant edit displays current configuration (not GUI). Creature stock is manually replenished; item shop timers do not apply. Ordinary item shops still use Gold. Requires Economy 0.3.0 and matching creature mod to populate catalogs. No payment processing. Test in game before deployment.
