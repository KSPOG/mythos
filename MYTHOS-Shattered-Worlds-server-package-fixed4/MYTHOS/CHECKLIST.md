# MYTHOS project checklist

## First playable chapter

- [x] Implement the spawn hub builder, class previews, arrival protection, and survival exit.
- [ ] Build the hub on the live server and verify first join, protection, class selection, exit, and restart.
- [ ] Add a one-time starter kit and combat tutorial for each class.
- [ ] Build Chapter 1 with a quest hub, exploration zone, dungeon, and boss.
- [ ] Persist quest progress, checkpoints, and reward claims.
- [ ] Make gear earnable through quests, drops, crafting, and bosses.
- [ ] Complete Chapter 1 end to end on a fresh vanilla account.

## Progression, combat, and economy

- [ ] Add XP, levels, and weapon mastery with meaningful unlocks.
- [ ] Give all eight classes distinct solo and party roles, including Cleric support and actual Summoner summons.
- [ ] Decide armour progression and eligibility.
- [ ] Add parties, quest credit, and fair boss rewards.
- [ ] Add currency, vendors, safe trading, and currency sinks.
- [ ] Define survival, building, PvP, death, and loot rules.

## Closed beta and launch

- [ ] Offer the resource pack on join and decide which armour visuals to add.
- [ ] Test server-side restrictions, inventory edge cases, and one-time rewards.
- [ ] Set up staging, backups, restore tests, monitoring, and a player load test.
- [ ] Define what carries forward into each chapter.
- [ ] Set up moderation, reporting, and cosmetic-only supporter perks.
