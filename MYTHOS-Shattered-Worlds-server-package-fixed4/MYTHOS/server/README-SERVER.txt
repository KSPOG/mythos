MYTHOS SERVER
=============

Run install.bat from the project root (or this folder's install.bat) to install Forge 52.1.5 and SpongeForge 1.21.1-52.1.5-12.0.3.
Run build.bat from the project root to compile MYTHOS and copy Mythos.jar into this server's mods folder.
Read https://www.minecraft.net/eula. If you agree, edit eula.txt and set eula=true.
Run start.bat from the project root or this folder to start the dedicated server.

Java 21 is required. The server keeps online-mode=true and whitelist enabled. Add players from the server console with: whitelist add <MinecraftName>.
