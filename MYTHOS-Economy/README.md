# MYTHOS Economy 0.1.0
Minecraft 1.21.1 / Forge 52.1.5 / Java 21. Standalone server-side mod; vanilla clients by design.
One integer virtual currency: Gold. New accounts start at zero; cap 9,000,000,000,000. UUID-based accounts, online player payments, operator grants and deductions with required reasons. /gold, /balance, /pay <player> <amount>, /economy balance, /economy history; operators /economy balance <player>, /economy history <player>, /economy grant <player> <amount> <reason>, /economy take <player> <amount> <reason>.
World file mythos-economy.json stores balances and last 1000 global transactions, with sequence, timestamp, actor, endpoints, reason. Each currency transaction writes a new complete snapshot with forced file contents and atomic replace before updating visible state. Invalid input, insufficient funds and overflow rejected; storage failure locks ledger. No automatic repair or reset. Back up ledger with server stopped. No full permanent audit archive or directory fsync; abrupt power loss guarantees depend on filesystem. Synchronous whole-ledger write per mutation, suitable for initial testing rather than unbenchmarked high-volume production.
API: com.ksp.mythoseconomy.EconomyApi.available(server), balance(server, UUID), transfer(server, from, to, amount, reason), debit(server, actor, player, amount, reason), credit(server, actor, player, amount, reason). Trusted server mods only, server thread required. A receipt reports success and sequence. Currency-only atomicity; these calls do NOT make another mod's inventory/collection grant atomic. Implement durable purchase intents and idempotent fulfillment before connecting merchants, mounts or pets; do not simply debit then grant. No migration of test wallets; RPG foundation PR #36 has its own economy draft which must be reconciled before merge. No bank, auction, tax, physical gold conversion, automatic rewards or NPC integration yet. No player permissions for mint/burn. Test classes cover reload, arithmetic, failed writes and corrupt storage. CI and live verification pending.

## 0.2.0
Durable merchant receipt IDs with immutable transaction semantics. Existing balances migrate automatically; receipts are retained indefinitely (growth not benchmarked). Merchant inventory delivery is not part of ledger atomicity. See merchant recovery instructions.

## 0.3.0
Currencies gold, mount_token, pet_token. /economy grant <player> <currency> <amount> <reason>, take likewise; legacy Gold commands unchanged. /economy currencies lists IDs. Token transfer/conversion unavailable. Creature offer currency, stock and ownership commit together with payment. Trusted server provider API requires a registered available creature provider. Existing Gold balances retained. Legacy creature wallet balances not automatically imported. Other mods require integration. Do not downgrade ledger after creating token balances or entitlements.
