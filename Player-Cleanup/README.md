# Player Cleanup 0.1.0
Forge 52.1.5 / Minecraft 1.21.1 / Java 21. Standalone server-side. Operator commands: `/remove <player> preview`, `/remove <player>`, `/remove <player> blocks`, `/remove <player> entities`, `/remove status`, `/remove cancel`. Names remembered on login; UUID accepted. Tracks Forge player block placements and breaks, including multi-block events. Restores prior block state only if current state still matches recorded placement; skips fluids and block entities. Entity support initially limited to entities explicitly tagged `playercleanup_owner_<UUID>` by trusted integrations; ordinary spawn eggs, vehicles and decorations are not automatically attributed yet. No historical attribution, undo, SQLite, radius, boss bar, persistent cleanup queue, or piston/explosion tracking in this initial implementation. JSON ownership store saved every second and at shutdown; backup world before testing. Neighbor updates may affect attached blocks; same-state external edits cannot be distinguished. `-Dplayercleanup.batch=64` controls per-tick operations. CI and runtime verification required.
