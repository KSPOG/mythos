# Player Cleanup 0.1.1
Forge 52.1.5 / Minecraft 1.21.1 / Java 21. Standalone server-side.
Commands: /remove <player> [preview|blocks|entities], /remove status, /remove cancel.
Includes tracked containers, signs, beds, decorative blocks and confirmed bucket source fluids. Clearable inventories are emptied before removal (no intended item drops). Dynamic block properties no longer disqualify a matching block type. Player break events invalidate ownership. Original block entity restoration is skipped because prior NBT is not captured. Fluid spread is not attributed. Explicitly tagged entities remain supported; automatic attribution of ordinary spawn eggs/vehicles/decorations is not implemented in this patch. No historical ownership, undo or piston/explosion tracking. Same-type external changes may be indistinguishable. Neighbor changes can affect adjacent blocks. JSON data retained from 0.1.0. Backup before testing. CI and runtime tests pending.
