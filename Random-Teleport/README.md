# Random Teleport v0.1.0
Minecraft 1.21.1 / Forge 52.1.5 / Java 21. Standalone server-side, operator level 2, Overworld only.
- /rtp: vanilla spreadplayers centered on current position.
- /rtp flat [size] [relief]: randomized site search, default 320x320 and 3-block maximum surface height range.
- /rtp status and /rtp cancel.
Search checks up to 200 candidates within configured square radius, using 25 coarse samples then every surface column of surviving sites. Rejects non-grass/dirt surfaces, liquids, trees, most buildings and nonpreferred biomes; no structure or claim database integration, no underground checks. Chunk tickets released on cancellation, completion, logout, dimension change or shutdown. At most one search, 512 columns and soft 3 ms survey budget per tick; asynchronous chunk generation itself may still cause load. Chunk wait timeout 200 ticks. Teleports to minimum X/Z corner and reports exact bounds and observed heights. No terrain edits. Not guaranteed to find an acceptable area; relax relief if needed. World may change after survey. Config generated on first use, read on each new command: radius=5000, searchRadius=50000, flatAreaSize=320, maxHeightDifference=3, preferredBiomes=minecraft:plains,minecraft:sunflower_plains,minecraft:savanna,minecraft:meadow. Existing configs use defaults for missing keys. CI and in-game verification pending.
