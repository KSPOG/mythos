# Random Teleport v0.1.1
Forge 52.1.5 / Minecraft 1.21.1 / Java 21. Operator-only Overworld commands: /rtp, /rtp flat [size] [relief], /rtp status, /rtp cancel.
Crash mitigation: flat search only inspects chunks already available via getChunkNow, never requests chunk tickets or synchronous loading. Candidate range capped by (view distance - 2)*16, smaller than configured searchRadius if needed. Up to 128 columns and soft 1ms per tick. A missing chunk rejects the candidate. Large footprints may not fit; explore a suitable plains area first or use smaller footprint. Grass, ferns and flowers are tolerated. Full surface validation still required. Existing config retained. Ordinary /rtp still invokes vanilla spreadplayers and may generate terrain; avoid using it if server is struggling. No crash report was supplied, so exact crash cause unconfirmed. No runtime stress test yet.
