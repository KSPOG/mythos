# Random Teleport v0.1.3
Forge 52.1.5 / Minecraft 1.21.1 / Java 21. Operator-only Overworld commands: /rtp, /rtp flat [size] [relief], /rtp status, /rtp cancel.
Flat terrain search independent of player view distance, up to 512x512. Uses getChunkNow and chunk-local reads exclusively, no blocking getChunk or future joins in survey. At most one level-33 FULL survey ticket at once, 20 tick cooldown after release before requesting another, 600 tick timeout per chunk, periodic refresh. Chunk generation can still impose server load; runtime stress test required. Full survey validates all columns, tolerates small vegetation and filters configured biomes. Releases ticket on rejection, cancellation, logout, completion or shutdown. Up to 128 columns and soft 1ms per tick; max 200 candidate attempts. Configuration unchanged. Ordinary /rtp still vanilla spreadplayers. No guarantee of finding a suitable site or of zero generation overhead. Backup before testing.

## Biome teleport (v0.1.3)
`/rtp biome plains`, `/rtp biome minecraft:dark_forest`, `/rtp biome "sunflower plains"` or `/rtp biome list`. Tab completion from the biome registry. Random candidate chunks within searchRadius; inspect 16 evenly spaced surface points per candidate, require matching sampled biome and safe dry support with two clear blocks above. No city footprint or elevation restriction. Surface-only Overworld search, so ocean/cave/Nether/End biomes may be unsupported or impossible to land safely in. Search uses existing one-ticket nonblocking lifecycle and 200 candidate cap. Biome lookup is quart-resolution, so boundaries are approximate. No guarantee of finding rare biomes. CI and runtime testing required.
