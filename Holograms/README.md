# Holograms v0.1.1
Forge 52.1.5 / Minecraft 1.21.1 / Java 21. Server-only. Uses persistent vanilla text_display entities. Operator level 2. /hologram create <id> <text> creates at your position +2.2 Y; /hologram text <id> <text>; /hologram move <id>; /hologram scale <id> <0.25–5>; /hologram delete <id>; /hologram list. Use & color codes, {newline} for multiple lines. IDs local to loaded entities within 128 blocks in current dimension; use unique IDs manually, duplicate distant IDs can exist. Stand near a hologram to edit. Vanilla entities persist in world saves; no separate database or forced chunk loads. Runtime verification pending. No animated/dynamic placeholders yet.

## Optional scrolling
`/hologram scroll <id> on [width] [ticks]` enables horizontal marquee scrolling on each line exceeding the width (default 24 Unicode code points, one character every 4 server ticks). Width 4–80, step interval 2–100 ticks. `/hologram scroll <id> off` restores full text. Formatting and multiline source are retained, scroll settings saved in entity Forge persistent data, animation restarts on chunk reload. Short lines stay static. Existing holograms remain static unless enabled. Editing text while scrolling updates the original source. Loaded entities only, no forced chunk loading. Width is characters rather than exact pixel width; vanilla wrapping can still occur for wide text or large scale. Compilation and in-game verification pending.
